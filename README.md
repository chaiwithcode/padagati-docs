# PadaGati public documents

A small, docs-only site for the PadaGati iPhone app. It contains the privacy policy and support guidance; it does not contain app source or user data.

**Website:** <https://chaiwithcode.github.io/padagati-docs/>

## Pages

- [Home](https://chaiwithcode.github.io/padagati-docs/)
- [Privacy policy](https://chaiwithcode.github.io/padagati-docs/privacy/)
- [Support](https://chaiwithcode.github.io/padagati-docs/support/)

## Hosting

This site is arranged for the repository `chaiwithcode/padagati-docs`. To serve it with GitHub Pages, put these files at the repository root and select **Deploy from a branch**, branch `main`, folder `/ (root)` in the repository’s Pages settings. The `.nojekyll` file keeps Pages from applying Jekyll processing to the static site.
